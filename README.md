# Neuroscience Agent Skills

Reusable AI agent skills for neuroscience research, dataset discovery, literature notes, and empirical analysis workflows.

## Skills

| Skill | Function | Covers / Searches | Output |
|---|---|---|---|
| `neuroscience-database-lookup` | Finds neuroscience datasets, data portals, educational anatomy resources, visual stimuli, and data descriptor article fallbacks. | OpenNeuro, OSF, Figshare, Dryad, Harvard Dataverse, Science Data Bank, Zenodo, Scientific Data, TDBRAIN, MSU EEG links, Narayanan Lab datasets, Human Connectome Project, BRAVA, NITRC ICBM MRA, Oliva Lab, BOSS, ABCD fMRI tasks, LaMem, FIGRIM, Torralba eye movement data, TEMCA2/FAFB, BrainFacts 3D Brain. | Ranked dataset links, repository/access notes, DOI/accession IDs, file formats, licenses, citations, and article fallbacks when direct data links are unavailable. |
| `obsidian-literature-notes` | Converts sources into Obsidian-compatible literature notes with rigorous methodology extraction. | Papers, PDFs, articles, web pages, pasted text, empirical studies, reviews, methods papers, theory papers, and note types such as literature notes, permanent notes, fleeting notes, and MOCs. | Vault-ready Markdown with YAML frontmatter, tags, wikilinks, source metadata, structured methods, results, limitations, and reproducibility gaps. |
| `scientific-research-data-analysis` | Governs scientific analysis from planning to results while protecting reproducibility and interpretation discipline. | Hypotheses, datasets, preprocessing, exclusions, statistics, null models, permutation tests, provenance, result interpretation, lab journals, theory updates, and analysis audits. | Frozen analysis plans, data contracts, configs, validation checks, controls, result manifests, audit notes, and restrained interpretation summaries. |
