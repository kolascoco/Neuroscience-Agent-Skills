# DFG Grant Writing

Guidance for producing DFG proposals that survive peer review: eligibility → structure →
section-by-section drafting → language → budget → submission.

**Currency warning.** DFG revises its forms roughly twice a year, and the section numbering
and page limits changed materially in the 06/26 revision of form 54.01. Figures here reflect
**form 54.01 version 06/26**. Confirm the version the user's elan portal serves before
finalising anything — and if a draft uses older section numbers (e.g. "1.2.2" for research
data), flag it, because those numbers no longer exist.

for a Sachbeihilfe section 2.3 is often wrong for an Emmy Noether proposal.

## Phase 1 — Eligibility and programme

Confirm before drafting:

1. **Doctorate** (as a rule) completed.
2. **Affiliation** with a German research institution, or a German institution abroad.
3. The institution is **non-profit** and permits immediate publication of findings.
4. **Duty to cooperate** (*Kooperationspflicht*, form 55.01) applies at Max Planck,
   Fraunhofer, Helmholtz and Leibniz institutes, publicly funded associated institutes,
   and international research facilities in Germany.

| Programme | For whom | Duration |
|-----------|----------|----------|
| Research Grant (*Sachbeihilfe*) | Any researcher post-doctorate, any field | 3 years initial; renewal up to 3 more |
| Walter Benjamin | Early postdoc, independent project | 24 months |
| Emmy Noether | Establishing an independent research group | 6 years (36 + 36) |
| Heisenberg | Qualified for a permanent professorship | Variable |
| Reinhart Koselleck | Exceptional track record; high-risk research | Up to 5 years |

Sachbeihilfe proposals may be submitted **at any time** — no standing deadline.

## Phase 2 — The research idea

Before prose exists, the applicant must answer four questions in one sentence each. A
proposal built on a fuzzy idea fails review however well written, so do not draft until
these are sharp:

1. **What is unknown, and why does that matter?**
2. **What will the project do?** Concrete experiments, analyses, deliverables.
3. **Why is it feasible?** Preliminary work, infrastructure, expertise.
4. **What new knowledge results, and is it proportionate to the funds requested?**

If the user cannot answer these, work through them conversationally first — the
highest-value early intervention.

**DFG funds new work.** Results already obtained, even unpublished, cannot be the basis of
a new project. Preliminary work is evidence of capability, not the project itself.

## Phase 3 — Structure (form 54.01, version 06/26)

### The three parts

| Part | Content |
|------|---------|
| **A** | Proposal data, obligations, summary (≤3,000 characters, **German and English**) |
| **B** | Project Description — scientific core, elan template (form 53.01) |
| **C** | Attachments — CV on template **53.200** (mandatory), ethics votes, letters |

### Part B page budget — changed in 06/26

| Block | Limit |
|-------|-------|
| **Total project description** | **25 pages** |
| **Sections 1–3** (science + publication list) | **17 pages** |
| **Sections 4 onward** | **8 pages** |

There is **no separate limit for the introduction** — sections 1, 2 and 3 share one 17-page
budget that the applicant allocates. At Arial 11 pt / 1.2 spacing a page holds roughly
500–600 words, so sections 1–3 total ~9,000–10,000 words *including* the publication list,
which typically consumes 1.5–3 pages.

Workable default allocation for an empirical project:

| Section | Typical pages |
|---------|---------------|
| 1 Starting point (state of the art + preliminary work) | 5–7 |
| 2.1 Duration | <0.25 |
| 2.2 Objectives | 0.5–1 |
| 2.3 Work programme and methods | 6–8 |
| 2.4 Handling of research data | 0.5–1 |
| 2.5 Sex, gender and/or diversity | 0.25–0.5 |
| 3 Publication list | 1.5–3 |

If a draft runs long, cut from section 1 first — reviewers penalise a thin work programme
far more than a compressed literature review.

### Section map — use these numbers, not the pre-2026 ones

```
1   Starting point — state of the art and preliminary work
2   Objectives and work programme
2.1   Anticipated total duration
2.2   Objectives
2.3   Work programme incl. proposed research methods
2.4   Handling of research data                    <- NOT 1.2.2 any more
2.5   Relevance of sex, gender and/or diversity    <- NOT 2.2 any more
3   Project- and subject-related list of publications
4   Supplementary information on the research context   (8-page block starts here)
5   Requested modules/funds
```

Section-by-section detail, all of section 4's sub-items, and the document naming protocol
are in `references/structure-and-forms.md`. Read it before drafting an individual section.

### Three requirements applicants most often miss

- **Research data management (2.4)** — mandatory. Cover data characteristics and scope,
  documentation and quality, storage and archiving, legal obligations, reuse and long-term
  accessibility, responsibilities and resources. If the project generates no relevant data,
  state that explicitly rather than omitting the section.
- **Sex, gender and/or diversity (2.5)** — mandatory to address, even if only to explain
  briefly why it is not relevant. Never omit.
- **AI disclosure** — if generative AI was used to prepare text or images, disclose it in a
  scientifically appropriate manner. Raise this proactively when helping draft substantial
  text.

### Self-containment

Reviewers are **not required to read any cited work**. Every claim the argument rests on
must be comprehensible from the proposal text alone. When reviewing a draft, flag sentences
whose meaning depends on having read the reference.

## Phase 4 — Modules and budget

Requests are made through **modules**. The Basic Module covers most needs; others are added
alongside it.

| Module | Form | Purpose |
|--------|------|---------|
| Basic Module | 52.01 | Staff, direct project costs, instrumentation, publication allowance |
| Temporary Positions for PIs | 52.02 | The applicant's own position |
| Replacements | 52.03 | Cover for teaching/administrative release |
| Temporary Substitutes for Clinicians | 52.04 | Cover for patient-care duties |
| Mercator Fellows | 52.05 | Long-term exchange with researchers in Germany or abroad |
| Project-Specific Workshops | 52.06 | Project-related workshops and colloquia |
| Public Relations | 52.07 | Presenting the work to a lay public |
| Standard Allowance for Equity and Diversity | 52.14 | Up to €1,000 per funding year |

**No budget ceiling**, but proportionality is enforced: every item must follow visibly from
the work programme, and the work programme must justify every item.

Personnel are funded at **standard annual rates** (form 60.12), not actual salaries. 2026
rates, eligible/non-eligible categories, instrumentation thresholds, core-facility usage
costs and worked justifications are in `references/modules-and-budget.md`.

**Weak:** "We request funding for one postdoctoral researcher for 24 months."

**Strong:** "We request a postdoctoral position (100%, 24 months, months 7–30) to conduct
WP2. The position requires expertise in [technique], not currently available in the
applicant's group. The 24 months comprise four measurement cycles of five months plus four
months for analysis and manuscript preparation."

## Phase 5 — Language and style

Write for an **informed scientist outside the sub-field**. Full guidance in
`references/language-and-style.md`; essentials:

- **Calibrate confidence.** Hedge *predictions* ("we anticipate", "we hypothesise"); be
  direct about *planned actions* ("we will measure", "we will compare").
- **Name agents.** "Smith and Jones (2021) showed…", not "It has been shown…". Active voice.
- **Topic-sentence-first paragraphs.** If a paragraph cannot be summarised in one sentence,
  it holds two ideas — split it.
- **Specific verbs.** Replace "investigate", "explore", "study" with "measure", "quantify",
  "test hypothesis H2", "compare A and B using method C".
- **Objectives are deliverables**, not aspirations: "To determine whether X regulates Y
  under conditions Z", not "To better understand X".
- **One language throughout** the project description; the Part A summary is always required
  in both German and English.

### Work package template

1. **Goal** — one sentence
2. **Rationale** — why necessary, and why at this point in the sequence
3. **Methods** — specific enough to judge feasibility
4. **Outcome** — what will exist at the end
5. **Timeline** — months, and dependencies on other WPs

### Hypotheses

State each as **directional, singular and testable**, mapped to a work package and an
outcome measure. A hypothesis that cannot fail is not a hypothesis. Where several form a
set, show the logic connecting them rather than listing them — reviewers reward a designed
set over an inventory.

## Integrity requirements

Not stylistic preferences; violating these can sink an otherwise fundable proposal.

- **Never reproduce text from published sources.** If a user supplies passages copied from a
  review or paper — including with reference markers intact — say so plainly and rewrite
  from scratch. Unattributed verbatim text is plagiarism under DFG's rules on good research
  practice.
- **Distinguish own work from others' work** explicitly throughout. Absence of this
  distinction may itself constitute a breach of good research practice.
- **Never invent citations, parameters, effect sizes or statistics.** If a number cannot be
  verified from the primary source, mark it for the user to check rather than supplying a
  plausible value.
- **Cite preprints as preprints**, and check whether a peer-reviewed version now exists
  before a claim rests on one.
- **Disambiguate same-surname authors** with initials — conflating unrelated authors who
  share a surname misleads reviewers.
- **Disclose AI use** in preparing the proposal.

## Pre-submission checklist

- [ ] Current elan template (verify version; 06/26 or later)
- [ ] Sections 1–3 ≤ **17 pages**; sections 4+ ≤ **8 pages**; total ≤ **25 pages**
- [ ] Body font ≥ Arial 11 pt; publication list ≥ Arial 9 pt; line spacing ≥ 1.2
- [ ] Template formatting, headings and numbering unchanged
- [ ] **2.4 Research data management** present and substantive
- [ ] **2.5 Sex/gender/diversity** addressed (or explicit non-relevance statement)
- [ ] Section 4 complete, incl. ethics/legal, DURC, international-cooperation risk, and
      ecological sustainability reflection where applicable
- [ ] Own vs. others' work clearly distinguished throughout
- [ ] Preliminary work cited with publication dates; prior DFG funding referenced with stage
- [ ] Bibliography lists **all authors** (no "et al."); only works cited in sections 1–2
- [ ] ≤10 own publications highlighted (global cap, even with several applicants)
- [ ] Every budget item traceable to a work package
- [ ] Part A summary ≤3,000 characters, lay-readable, **German and English**
- [ ] CV on template **53.200**, ≤4 pages, no photograph, named `CV_PubList_<lastname>`
- [ ] CV publication list: Category A ≤10, Category B ≤10
- [ ] Letters of collaboration for named partners; employer statement (41.027) if applying
      for a Temporary Position for PIs
- [ ] Declarations 41.028/41.029 if commercial enterprises are involved
- [ ] Ethics/animal approvals in hand or applied for
- [ ] **AI use disclosed** if applicable
- [ ] PDFs ≤10 MB each, no security restrictions, named per the DFG naming protocol
- [ ] All co-applicants registered in elan
