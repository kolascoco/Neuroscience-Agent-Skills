# Neuroscience Agent Skills

Reusable AI agent skills for neuroscience research, dataset discovery, literature notes, and empirical analysis workflows.

## Skills

| Skill | Function | Output |
|---|---|---|
| `neuroscience-database-lookup` | Finds neuroscience datasets, data portals, educational anatomy resources, visual stimuli, and data descriptor article fallbacks across OpenNeuro, OSF, Figshare, Dryad, Harvard Dataverse, Science Data Bank, Zenodo, Scientific Data, TDBRAIN, MSU EEG links, Narayanan Lab datasets, Human Connectome Project, BRAVA, NITRC ICBM MRA, Oliva Lab, BOSS, ABCD fMRI tasks, LaMem, FIGRIM, Torralba eye movement data, TEMCA2/FAFB, and BrainFacts 3D Brain. | Ranked dataset links, repository/access notes, DOI/accession IDs, file formats, licenses, citations, and article fallbacks when direct data links are unavailable. |
| `obsidian-literature-notes` | Converts papers, PDFs, articles, web pages, pasted text, empirical studies, reviews, methods papers, and theory papers into Obsidian-compatible literature notes with rigorous methodology extraction. | Vault-ready Markdown with YAML frontmatter, tags, wikilinks, source metadata, structured methods, results, limitations, and reproducibility gaps. |
| `scientific-research-data-analysis` | Governs hypotheses, datasets, preprocessing, exclusions, statistics, null models, permutation tests, provenance, result interpretation, lab journals, theory updates, and analysis audits while protecting reproducibility and interpretation discipline. | Frozen analysis plans, data contracts, configs, validation checks, controls, result manifests, audit notes, and restrained interpretation summaries. |
